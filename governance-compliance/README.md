# Governance and Compliance Notes

This folder contains practical notes about governance, compliance and risk topics related to identity and access management.

The focus is not legal theory.

The focus is how standards, regulations and audit topics show up in real access work.

## Main idea

Governance and compliance are not separate from daily IT work.

They show up in access requests, user lifecycle, system ownership, privileged access, external users, logs and audit evidence.

If access cannot be explained later, the process is weaker than it looks.
