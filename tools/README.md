# IAM Tools and Platforms

This folder contains notes about commonly seen tools and platforms related to identity, access management, governance, privileged access and IT operations.

The important part is to understand the main tool categories and how they connect.

## Tool categories

| Category | What it helps with | Examples |
|---|---|---|
| Directory / identity platform | Where users, groups and identities live | Microsoft Entra ID, Active Directory, Okta |
| IGA | How access is requested, approved, reviewed and removed | SailPoint, Saviynt, Entra ID Governance |
| PAM | How admin and privileged access is controlled | CyberArk, BeyondTrust, Entra PIM |
| ITSM | Where tickets, approvals and workflows happen | ServiceNow, Jira Service Management |
| Cloud IAM | How permissions are managed in cloud environments | Azure, AWS IAM, Google Cloud IAM |
| HR source | Where employee data and JML triggers come from | Workday, SuccessFactors |

## Commonly seen tools

| Tool / Platform | Category | What it is used for |
|---|---|---|
| Microsoft Entra ID | Directory / identity platform | Cloud identity, users, groups, roles, authentication, Conditional Access and Microsoft 365 identity |
| Active Directory | Directory / identity platform | On-premises users, groups, devices, domain access and traditional enterprise identity |
| Microsoft Graph | API / automation | Managing Microsoft 365 and Entra data through API calls, PowerShell and automation |
| Microsoft Graph PowerShell | API / automation | Practical identity management with PowerShell commands through Microsoft Graph |
| Entra ID Governance | IGA | Access reviews, entitlement management, access packages and lifecycle workflows |
| Entra PIM | PAM | Just-in-time privileged role activation, approvals and role review in Microsoft environments |
| Okta | Directory / identity platform | SSO, application access, identity integrations and user lifecycle management |
| SailPoint | IGA | Identity governance, access requests, access certifications, lifecycle management and compliance |
| Saviynt | IGA | Identity governance, cloud access governance, application access and compliance automation |
| CyberArk | PAM | Privileged account protection, credential vaulting, session control and admin access security |
| BeyondTrust | PAM | Privileged access management, remote support, credential control and session monitoring |
| ServiceNow | ITSM | Access request tickets, approvals, workflows, incidents, changes and service management |
| Jira Service Management | ITSM | Service requests, approvals, support tickets and workflow tracking |
| SAP | HR source | HR data source for identity lifecycle, provisioning and organizational changes |
| AWS IAM | Cloud IAM | Users, roles, policies and permissions inside AWS environments |
| Google Cloud IAM | Cloud IAM | Roles, service accounts and permissions inside Google Cloud environments |
| GitHub Enterprise | Application / developer access | Repository access, teams, SSO, SCIM provisioning and audit logs |
