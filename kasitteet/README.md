# Käsitteet

Tähän kansioon kerään IAMiin, tietoturvaan, identiteettiin ja käyttöoikeuksiin liittyviä käsitteitä.

Tavoite on selittää käsitteet omin sanoin, käytännönläheisesti ja niin selkeästi, että ne eivät jää pelkäksi lyhennejargoniksi.

---

## Kategoriat

| Kategoria | Sisältö |
| :--- | :--- |
| [`iam/`](./iam/) | IAMin peruskäsitteet, identiteetti, access ja käyttäjän elinkaari |
| [`authentication/`](./authentication/) | Todentaminen, valtuutus, MFA, SSO ja Conditional Access |
| [`protocols/`](./protocols/) | SAML, OAuth 2.0, OIDC, SCIM ja integraatiot |
| [`microsoft-entra/`](./microsoft-entra/) | Microsoft Entra ID, Azure AD / AAD, AD DS ja Microsoftin identiteettikäsitteet |
| [`governance/`](./governance/) | IGA, access review, RBAC, ABAC, SoD ja governance-ajattelu |
| [`privileged-access/`](./privileged-access/) | PAM, PIM, JIT access ja break glass -tilit |
| [`security-compliance/`](./security-compliance/) | ISO/IEC 27001, GDPR, NIS2, riskit ja tietoturvan peruskäsitteet |

---

## Kirjoitustyyli

Selitän käsitteet omin sanoin.

Osa teksteistä voi olla suomeksi, osa englanniksi. Tärkeintä on, että ymmärrän itse mitä olen kirjoittamassa.
