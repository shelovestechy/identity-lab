# IAM Projects

This folder contains larger case studies that combine identity lifecycle, access control, governance and security thinking.

## Projects

| Project | Scope | Evidence status |
| :--- | :--- | :--- |
| [Microsoft Entra ID Zero Trust Baseline](./entra-zero-trust-baseline/) | Authentication, Conditional Access, privileged access, JML, guest and application governance, monitoring and risk mapping | Design case study; selected controls are described as lab simulations, but technical evidence is not yet published |

## Scope note

These projects are learning artifacts, not production implementations. Each project should distinguish between:

- controls tested in a lab
- scenarios simulated on paper
- future improvements

The next improvement for this folder is to pair each design with one small, sanitized and reproducible technical artifact.
