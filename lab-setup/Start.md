# IAM Lab Setup

This document describes the tools, software and environment used for my IAM learning lab.

The purpose of this lab is to practise identity and access management concepts in a safe test environment, document what I learn and build practical understanding of Microsoft Entra ID, Microsoft Graph PowerShell and access lifecycle thinking.

## Tools Installed

- Visual Studio Code
- Git
- PowerShell 7
- Microsoft Graph PowerShell SDK
- Microsoft Entra PowerShell module
- Microsoft Edge
- Google Chrome / Firefox
- diagrams.net
- Postman

## Cloud Environment

- Microsoft Entra ID test tenant
- Microsoft 365 admin center, if available
- Microsoft Graph Explorer

## Planned Lab Areas

- User management
- Group management
- Role-based access
- Access requests
- Joiner, mover and leaver scenarios
- Conditional Access basics
- Identity governance basics
- PowerShell and Microsoft Graph practice

## Notes

This lab is a personal learning environment. The goal is not only to test tools, but to understand how identity decisions affect users, security, operations and business processes.
